Logic and stuff?

Main function realistically should only begin the files/libraries and call them.
Main could also manage the timing of the control loop and maintain loop frequency.

Receiver handles:
    Reading PWM from the 4 receiver channels being used, and writes those values to receiver objects.
    Will also normalize receiver values with Receiver.update() so that Controller has fresh normalized values to ask for.
    Will have all the receiver interrupts.

IMU handles:
    Reading necessary values from the IMU and writing them to variables. 
    Converting IMU orientation to Aircraft orientation so that Controller only sees adjusted values.
    Will use polling and ask for a value when IMU.update() is called in main.

Controller handles:
    All PID math (integrals n stuff)
    Conversions from IMU quaternion to XYZ error
    Will house both the FBW mode and passthrough mode (handles all servo output)
    Also needs a way to calibrate aircraft orientation when switching between FBW and passthrough mode.
